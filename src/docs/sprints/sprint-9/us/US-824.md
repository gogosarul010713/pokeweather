# US-824 — Layout general: mapa como protagonista

**Sprint:** 9 — Sesión 3  
**Story Points:** 1 (reducido de 2 — ver DEC-904)  
**Prioridad:** Alta  
**Status:** Done — implementada y verificada 2026-06-28 (criterios ajustados, ver DEC-904)

---

## Historia de Usuario

> Como jugador, quiero que el mapa ocupe el espacio central de la pantalla con el sidebar fijo a la izquierda, para tener una experiencia de exploración donde el mapa siempre es visible.

---

## Criterios de Aceptación

- [x] Layout principal: `display: flex`, sidebar fijo a la izquierda, `MapView` con `flex: 1`
- [x] Sidebar tiene ancho fijo (300px desktop, 280px tablet) — **sin toggle de colapso en desktop/tablet** (ver DEC-904)
- [x] El mapa ocupa todo el espacio restante y no hace scroll — la página entera tiene `height: 100vh`, `overflow: hidden`
- [x] Header ocupa su espacio dentro del flex flow (`flex-direction: column`), no `margin-top` hardcodeado
- [x] Z-index scale documentado: mapa base (0), pins (10), overlay (15), sidebar (20), header (30), modales (100)
- [x] `MapView.tsx` permanece como archivo único — sin separación en subcarpetas en esta US

## Código de Ejemplo

### `src/App.tsx` — layout raíz

```tsx
// Estructura base
<div style={{
  display: 'flex',
  flexDirection: 'column',
  height: '100vh',
  overflow: 'hidden',
}}>
  <Header />   {/* height fija, ~52px */}

  <div style={{
    display: 'flex',
    flex: 1,
    overflow: 'hidden',
  }}>
    <Sidebar />       {/* ancho fijo, colapsable */}
    <MapView />       {/* flex: 1, ocupa el resto */}
  </div>
</div>
```

### `src/components/Sidebar/Sidebar.tsx` — ancho fijo, sin toggle en desktop/tablet

```tsx
// Sin estado de colapso en desktop/tablet — el sidebar siempre es visible.
// El toggle de mostrar/ocultar sigue existiendo solo en mobile, vía BottomSheet.
<div style={{
  width: '300px',          // 280px en tablet vía media query
  flexShrink: 0,
  overflow: 'hidden',
  borderRight: '1px solid var(--color-border)',
  display: 'flex',
  flexDirection: 'column',
  zIndex: Z.sidebar,
  position: 'relative',
}}>
  {/* contenido del sidebar */}
</div>
```

### `src/components/Map/MapView.tsx` — contenedor

```tsx
// El componente MapView ocupa el espacio restante
<div style={{
  flex: 1,
  position: 'relative',
  zIndex: 0,
  overflow: 'hidden',
}}>
  {/* MapContainer de react-leaflet aquí */}
  {/* Leyenda, detail panel, time chip — position: absolute dentro */}
</div>
```

### Z-index scale

```ts
// Referencia — usar estos valores en toda la app
export const Z = {
  mapBase:     0,
  mapPins:    10,
  mapOverlay: 15,   // leyenda, time chip, detail panel
  sidebar:    20,
  header:     30,
  modal:     100,
} as const
```

## Notas

- **Importante:** el código de ejemplo de la versión anterior de esta US sugería separar `MapView` en `ClimateMapView` y `NestMapView`. Ese refactor **no es parte de esta US**. `MapView.tsx` permanece como archivo único. Ver DEC-903 en decisions.md.
- **El toggle de colapso del sidebar en desktop/tablet (`SidebarToggle.tsx`, `sidebarOpen` en el store) se descarta para esta US.** No resuelve un problema real de uso — ver DEC-904 en decisions.md. Si `SidebarToggle.tsx` y el flag `sidebarOpen` quedan sin otro consumidor tras este cambio, evaluar su eliminación en limpieza posterior (no en esta US).
- El `margin-top` hardcodeado en `.app-body` (actualmente 80px desktop / 96px mobile, ver `App.tsx`) se reemplaza por el Header ocupando su espacio real dentro de `flex-direction: column` — elimina la necesidad de sincronizar dos valores de altura en archivos distintos.

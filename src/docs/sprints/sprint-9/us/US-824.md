# 📋 US-824 — Layout Redesign: Mapa = Elemento Principal

**Sprint:** 9 (Sesión 2 - Rediseño)  
**Story Points:** 3 SP  
**Prioridad:** P0  
**Status:** ⏳ Pendiente  
**Dependencias:** US-820, US-821, US-822, US-823  
**Sesión:** 2/3

---

## Historia de Usuario

> Como usuario, quiero que el mapa sea el elemento principal de la aplicación **para** que sea el foco central y el sidebar sea auxiliar (colapsable).

---

## Criterios de Aceptación

**Layout general:**
- [ ] Mapa ocupa **área máxima disponible** (center-stage)
- [ ] Mapa se expande cuando sidebar colapsa (US-822)
- [ ] Mapa se reduce cuando sidebar expande (permanece visible)
- [ ] Header permanece arriba de todo
- [ ] Sidebar permanece lado izquierdo (colapsable)

**Estructura DOM:**
```
<App>
  <Header /> 
  <main>
    <Sidebar /> (fixed, left: 0, colapsable)
    <MapContainer /> (flex: 1, se expande/contrae)
  </main>
  <Footer /> (opcional)
</App>
```

**Espaciado:**
- [ ] No hay "dead zones" — contenido no se superpone
- [ ] Transiciones suaves (300ms) al colapsar/expandir sidebar
- [ ] Responsive: en mobile, sidebar colapsa por default para dar más espacio al mapa

**Z-index scale:**
```
Header: z-index 100
Sidebar: z-index 100 (mismo que header, lado izquierdo)
Sidebar Toggle: z-index 101
Popups/Modals: z-index 200+
```

### MapView.tsx

```tsx
import { MapContainer, TileLayer } from 'react-leaflet'
import ClimateMapView from './Climate/ClimateMapView'
import NestMapView from './Nests/NestMapView'
import { useStore } from '../store/useStore'
import './MapView.css'

export default function MapView() {
  const activeTab = useStore(s => s.activeTab)

  return (
    <div className="map-view">
      <MapContainer
        center={[0, 0]}
        zoom={2}
        className="map-container"
        style={{ width: '100%', height: '100%' }}
      >
        <TileLayer
          url="https://{s}.tile.openstreetmap.org/{z}/{x}/{y}.png"
          attribution='&copy; OpenStreetMap contributors'
        />

        {activeTab === 'clima' && <ClimateMapView />}
        {activeTab === 'nidos' && <NestMapView />}
      </MapContainer>
    </div>
  )
}
```

---

## Notas

- Z-index scale es crítica para evitar que elementos se superpongan
- `position: fixed` en Sidebar es intencional — permite que MapView (flex) ocupe resto del espacio
- `margin-left` en MapView se ajusta según sidebar state (colapsado/expandido)
- Si usas CSS-in-JS, importa variables CSS del design system

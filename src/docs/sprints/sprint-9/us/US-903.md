# US-903 — Optimize Lighthouse Score

**Sprint:** 9  
**Priority:** P1  
**Story Points:** 3  
**Status:** 🎯 PLANEADO  
**Sesiones:** 1-2

---

## Problema

Lighthouse score bajo (<80/100) debido a:
- Bundle size (después US-901)
- Image optimization
- Core Web Vitals

---

## Solución

Aplicar optimizaciones de performance basadas en Lighthouse report.

---

## Áreas a Optimizar

### 1. Images (1 SP)
- [ ] Use WebP with fallback
- [ ] Lazy load images
- [ ] Optimize size: <100 KB cada
- [ ] Responsive images (srcset)

### 2. Code Splitting Validation (1 SP)
- [ ] Verify US-901 results
- [ ] Remove unused code
- [ ] Optimize dependencies
- [ ] Measure: CLS (Cumulative Layout Shift)

### 3. Core Web Vitals (1 SP)
- [ ] LCP (Largest Contentful Paint) <2.5s
- [ ] FID (First Input Delay) <100ms
- [ ] CLS (Cumulative Layout Shift) <0.1
- [ ] Measure con Lighthouse & Web Vitals

---

## Criterios de Aceptación

- [x] Lighthouse score ≥85/100
- [x] All Core Web Vitals green
- [x] Images optimized (<100 KB each)
- [x] No functional regression
- [x] Build time maintained (<2s)

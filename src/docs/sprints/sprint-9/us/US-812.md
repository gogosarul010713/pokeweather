# 📋 US-812 — Diferenciación Visual de Pins en el Mapa

**Sprint:** 9 (Sesión 1)  
**Story Points:** 2 SP  
**Prioridad:** P0  
**Status:** ⏳ Pendiente  
**Dependencias:** US-811 (tabs del sidebar), US-819 (datos de nidos)

---

## Historia de Usuario

> Como usuario, quiero distinguir visualmente los pines de Clima y los pines de Nidos sin necesidad de leer la leyenda **para** no confundirme cuando ambas capas están activas (modo Todo).

---

## Criterios de Aceptación

- [ ] **Pines de Clima:** forma círculo (sin cambios respecto al estado actual)
- [ ] **Pines de Nidos:** forma **hexágono** con variante de color por tipo de Pokémon
- [ ] La diferenciación es por **forma + color**: no depende solo del color
- [ ] Los pines de ambas capas son distinguibles sin leer la leyenda
- [ ] Los hexágonos de nidos usan colores consistentes con el tipo de Pokémon (ver `TYPE_ICON_COLORS` en config)
- [ ] Tamaño de hexágonos: ~32px (visible pero no dominante en el mapa)
- [ ] Interactividad: click en hex abre popup con info del nido (delegado a MapPin)
- [ ] En modo Todo: ambas formas son visibles simultáneamente sin solapamiento visual confuso

## Código de Ejemplo

### NestPin.tsx (SVG Hexágono)

```tsx
import { useStore } from '../../store/useStore'
import { Marker, Popup } from 'react-leaflet'
import L from 'leaflet'

interface NestPinProps {
  nest: Nest
  isSelected: boolean
}

export default function NestPin({ nest, isSelected }: NestPinProps) {
  const setSelectedNest = useStore(s => s.setSelectedNest)
  const TYPE_COLORS: Record<string, string> = {
    'Normal': '#a8a878',
    'Fire': '#f08030',
    'Water': '#6890f0',
    'Grass': '#78c850',
    'Electric': '#f8d030',
    'Ice': '#98d8d8',
    'Fighting': '#c03028',
    'Poison': '#a040a0',
    'Ground': '#e0c068',
    'Flying': '#a890f0',
    'Psychic': '#f85888',
    'Bug': '#a8b820',
    'Rock': '#b8a038',
    'Ghost': '#705898',
    'Dragon': '#7038f8',
    'Dark': '#705848',
    'Steel': '#b8b8d0',
    'Fairy': '#ee99ac',
  }

  // SVG hexagon
  const hexagonSvg = `
    <svg width="32" height="32" viewBox="0 0 32 32">
      <polygon points="16,2 28,8 28,20 16,26 4,20 4,8" 
               fill="${TYPE_COLORS[nest.pokemonType[0]] || '#999'}" 
               stroke="white" stroke-width="1.5"/>
      <circle cx="16" cy="14" r="3" fill="white" opacity="0.8"/>
    </svg>
  `

  const icon = L.divIcon({
    html: hexagonSvg,
    className: 'nest-pin',
    iconSize: [32, 32],
    iconAnchor: [16, 16],
  })

  const handleClick = () => {
    setSelectedNest(nest)
  }

  return (
    <Marker position={[nest.lat, nest.lng]} icon={icon} eventHandlers={{ click: handleClick }}>
      <Popup>
        <div className="nest-popup">
          <h4>{nest.name}</h4>
          <p><strong>Pokémon:</strong> {nest.pokemon}</p>
          <p><strong>Tipo:</strong> {nest.pokemonType.join(', ')}</p>
          <p><strong>Ubicación:</strong> {nest.city}, {nest.country}</p>
        </div>
      </Popup>
    </Marker>
  )
}
```

### Integración en MapView.tsx

```tsx
import NestPin from './NestPin'

interface MapViewProps {
  cities: City[]
  nests?: Nest[] // nuevo
}

export default function MapView({ cities, nests }: MapViewProps) {
  const activeTab = useStore(s => s.activeTab)
  
  return (
    <MapContainer>
      {/* Existing climate pins */}
      {(activeTab === 'clima' || activeTab === 'todo') && (
        cities.map(city => <MapPin key={city.id} city={city} />)
      )}

      {/* Nuevo: Nest pins */}
      {(activeTab === 'nidos' || activeTab === 'todo') && nests && (
        nests.map(nest => <NestPin key={nest.id} nest={nest} />)
      )}
    </MapContainer>
  )
}
```

## Notas Técnicas

1. Usar **SVG inline** en lugar de imagen PNG para escalabilidad
2. Hexágono debe estar **centrado** en coordenadas (iconAnchor = mitad del tamaño)
3. Z-index: Climate pins < Nest pins (así los nidos aparecen arriba)
4. En modo Todo, los pins no deben solaparse. Si sucede, revisar US-806 (espaciamiento de nidos)

### Estructura de tabs

```
MapLegend
├── Tab: Clima
│   ├── Subtab: Tipo Clima  — sprite del clima + label (7 condiciones)
│   └── Subtab: Categoria   — icono + label (Pokestops, Gyms, Comunidad, Mejores)
└── Tab: Nidos
    ├── Subtab: Tipos        — grid 3 columnas, 18 tipos (chip borde-color + emoji + nombre)
    └── Subtab: Estado       — badges (✅ Verificado · ⭐ Mayor Spawn · ✨ Mayor Polvo)
```

### Decisiones de diseño
- Clima: sprite con fondo semitransparente del color de condicion + label. Reemplaza dot simple.
- Nidos/Tipos: grid 3col, sin scroll (18 tipos = 6 filas). Chip = borde del color oficial + emoji + nombre 8px. Sin campo de busqueda.
- Sin toggle "Iconos en pines" — se elimino de la leyenda.
- Jerarquia visual del jugador: especie Pokemon (sprite) > tipo (color del pin) > estado (badge).

## Código de Ejemplo

### NestLegend.tsx

```tsx
import { useState } from 'react'

const POKEMON_TYPES = [
  'Normal', 'Fire', 'Water', 'Grass', 'Electric', 'Ice',
  'Fighting', 'Poison', 'Ground', 'Flying', 'Psychic', 'Bug',
  'Rock', 'Ghost', 'Dragon', 'Dark', 'Steel', 'Fairy'
]

const TYPE_COLORS: Record<string, string> = { /* ... */ }

export default function NestLegend() {
  const [innerTab, setInnerTab] = useState<'types' | 'classification'>('types')
  const [searchTerm, setSearchTerm] = useState('')

  const filteredTypes = POKEMON_TYPES.filter(t =>
    t.toLowerCase().includes(searchTerm.toLowerCase())
  )

  return (
    <div className="nest-legend">
      <div className="legend-header">
        <label>
          <input type="checkbox" defaultChecked /> Mostrar iconos en pines
        </label>
      </div>

      <div className="legend-tabs">
        <button 
          className={innerTab === 'types' ? 'active' : ''}
          onClick={() => setInnerTab('types')}
        >
          Tipos
        </button>
        <button 
          className={innerTab === 'classification' ? 'active' : ''}
          onClick={() => setInnerTab('classification')}
        >
          Clasificación
        </button>
      </div>

      {innerTab === 'types' && (
        <div className="legend-types">
          <input
            type="text"
            placeholder="Buscar tipo..."
            value={searchTerm}
            onChange={e => setSearchTerm(e.target.value)}
          />
          <div className="types-grid">
            {filteredTypes.map(type => (
              <div key={type} className="type-item">
                <div className="type-hex" style={{ background: TYPE_COLORS[type] }} />
                <span>{type}</span>
              </div>
            ))}
          </div>
        </div>
      )}

      {innerTab === 'classification' && (
        <div className="legend-classification">
          <div className="classification-item">
            <span className="badge">✅</span> Verificado
          </div>
          <div className="classification-item">
            <span className="badge">⭐</span> Mayor Spawn
          </div>
          <div className="classification-item">
            <span className="badge">✨</span> Mayor Polvo Estelar
          </div>
        </div>
      )}
    </div>
  )
}
```

## Historia de Usuario

> Como usuario, quiero seleccionar entre Clima, Nidos o Todo desde tabs en el sidebar **para** controlar qué se muestra tanto en la lista como en el mapa, desde un único punto de control.

---

## Criterios de Aceptación

- [ ] El sidebar muestra tres tabs: `[☁️ Clima]` `[🔴 Nidos]` `[✦ Todo]` según diseño
- [ ] Siempre hay exactamente un tab activo — no es posible dejar ninguno sin seleccionar
- [ ] **Tab Clima:** muestra lista de ciudades + renderiza pines de Clima en el mapa (sin cambios vs actual)
- [ ] **Tab Nidos:** muestra lista de nidos + renderiza pines de Nidos en el mapa
- [ ] **Tab Todo:** muestra sidebar y filtros bloqueados (ver US-817) + renderiza ambas capas simultáneamente
- [ ] Cambiar entre tabs es la **única** forma de cambiar qué capas se ven en el mapa
- [ ] **Diseño de tabs (según requirements):**
  - Contenedor `flex row`, ancho completo del sidebar
  - Padding horizontal 8px, padding vertical 6px, gap 4px
  - Border-bottom 0.5px (color border-default)
  - NOTA: Validar con `@design.md` si existe; priorizar design.md si hay divergencia
- [ ] **Tab activo:** 
  - Pill con border-radius ~99px
  - Fondo superficie elevada clara (`--bg-elevated`)
  - Texto color primario (`--text-primary`), font-weight 500
  - Ícono izquierda 14px
- [ ] **Tab inactivo:** 
  - Fondo transparente
  - Texto color muted (`--text-muted`), font-weight 400
  - Ícono muted — sin borde visible
- [ ] Debajo de los tabs aparece un **contador contextual:**
  - Clima: `Ciudades · N`
  - Nidos: `Nidos · N`
  - Todo: `Ciudades · N Y Nidos · N`
- [ ] Estado del tab activo se persiste en localStorage (`pwe-activeTab`)
- [ ] Al recargar, se restaura el último tab activo

## Código de Ejemplo

### TabControl.tsx

```tsx
import { useStore } from '../../store/useStore'

interface TabControlProps {
  cityCount: number
  nestCount: number
}

export default function TabControl({ cityCount, nestCount }: TabControlProps) {
  const activeTab = useStore(s => s.activeTab)
  const setActiveTab = useStore(s => s.setActiveTab)

  const handleTabClick = (tab: 'clima' | 'nidos' | 'todo') => {
    setActiveTab(tab)
  }

  const getCounterText = () => {
    switch (activeTab) {
      case 'clima': return `Ciudades · ${cityCount}`
      case 'nidos': return `Nidos · ${nestCount}`
      case 'todo': return `Ciudades · ${cityCount} Y Nidos · ${nestCount}`
    }
  }

  return (
    <div className="tab-control">
      <div className="tab-buttons">
        <button
          className={`tab-button ${activeTab === 'clima' ? 'tab-active' : ''}`}
          onClick={() => handleTabClick('clima')}
        >
          <span className="tab-icon">☁️</span>
          <span>Clima</span>
        </button>
        
        <button
          className={`tab-button ${activeTab === 'nidos' ? 'tab-active' : ''}`}
          onClick={() => handleTabClick('nidos')}
        >
          <span className="tab-icon">🔴</span>
          <span>Nidos</span>
        </button>
        
        <button
          className={`tab-button ${activeTab === 'todo' ? 'tab-active' : ''}`}
          onClick={() => handleTabClick('todo')}
        >
          <span className="tab-icon">✦</span>
          <span>Todo</span>
        </button>
      </div>
      
      <div className="tab-counter">
        {getCounterText()}
      </div>
    </div>
  )
}
```

### Zustand Slice

```typescript
// En src/store/useStore.ts, agregar:

interface WeatherState {
  // ... existing state
  activeTab: 'clima' | 'nidos' | 'todo'
  setActiveTab: (tab: 'clima' | 'nidos' | 'todo') => void
}

const useStore = create<WeatherState>((set) => ({
  // ... existing state
  activeTab: localStorage.getItem('pwe-activeTab') as any ?? 'clima',
  
  setActiveTab: (tab) => {
    set({ activeTab: tab })
    localStorage.setItem('pwe-activeTab', tab)
  }
}))
```

## Notas Técnicas

1. **`activeTab` es la fuente única de verdad** para qué se renderiza en el mapa
2. Los tabs **no eliminan componentes del DOM**, solo los ocultan (usar condicionales de renderizado)
3. Al cambiar de tab, **se preserva el estado** de cada vista (ej: scroll position en lista)
4. localStorage se usa **solo para persistencia**, no para lógica en tiempo de ejecución
5. Validar con `@design.md` si existe — si hay divergencia, priorizar diseño

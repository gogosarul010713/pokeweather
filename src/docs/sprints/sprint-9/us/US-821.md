# 📋 US-821 — Panel de Filtros en Sidebar (Top)

**Sprint:** 9 (Sesión 2 - Rediseño)  
**Story Points:** 3 SP  
**Prioridad:** P0  
**Status:** ⏳ Pendiente  
**Dependencias:** US-820 (requiere sidebar sin tabs)  
**Sesión:** 2/3

---

## Historia de Usuario

> Como usuario, quiero que los filtros estén en la parte superior del sidebar **para** que sean fácilmente accesibles sin tener que ir al header.

---

## Criterios de Aceptación

**Panel de filtros ubicación:**
- [ ] Panel de filtros se **mueve de Header a Sidebar top**
- [ ] Posición: justo debajo de la barra de búsqueda (si existe) o al inicio de `.sb-content`
- [ ] Ancho: ocupa 100% del sidebar

**Filtros por capa:**

**Cuando capa Clima está activa:**
- [ ] Botón: `Todas`
- [ ] Dropdown: `Clima` (soleado, lluvia, viento, etc.)
- [ ] Dropdown: `Tipo` (tipo de Pokémon potenciado)
- [ ] Dropdown: `Ordenar por` → Temperatura, Pokémon potenciado

**Cuando capa Nidos está activa:**
- [ ] Dropdown Multi-select: `Tipo` (tipos de Pokémon del nido)
- [ ] Dropdown: `Ordenar por` → Nombre, Tipo, Spawn Rate
- [ ] Botón Restablecer (solo si hay filtros activos)

**Comportamiento general:**
- [ ] Filtros se reemplazan completamente al cambiar de capa
- [ ] Al cambiar de capa, filtros se resetean (no persistir)
- [ ] Transiciones suaves (fade-out/fade-in)
- [ ] Responsive en mobile

## Código de Ejemplo

### FilterPanel.tsx (wrapper en Sidebar)

```tsx
import { useStore } from '../../store/useStore'
import FilterPanelClima from './FilterPanelClima'
import FilterPanelNests from './FilterPanelNests'

export default function FilterPanel() {
  const activeTab = useStore(s => s.activeTab)

  if (activeTab === 'clima') return <FilterPanelClima />
  if (activeTab === 'nidos') return <FilterPanelNests />
  return null
}
```

### FilterPanelClima.tsx

```tsx
import { useStore } from '../../store/useStore'

export default function FilterPanelClima() {
  const { region, condition, type, sortBy } = useStore(s => ({
    region: s.region,
    condition: s.condition,
    type: s.type,
    sortBy: s.sortBy,
  }))
  const { setRegion, setCondition, setType, setSortBy } = useStore()

  return (
    <div className="filter-panel filter-panel-clima">
      <button className="filter-btn" onClick={() => { setRegion(null); setCondition(null) }}>
        Todas
      </button>
      
      <select value={condition || ''} onChange={e => setCondition(e.target.value || null)}>
        <option value="">Clima</option>
        <option value="sunny">Soleado</option>
        <option value="rainy">Lluvia</option>
        {/* ... más opciones */}
      </select>

      <select value={type || ''} onChange={e => setType(e.target.value || null)}>
        <option value="">Tipo</option>
        {/* ... opciones de tipo */}
      </select>

      <select value={sortBy || 'default'} onChange={e => setSortBy(e.target.value)}>
        <option value="default">Ordenar por</option>
        <option value="temp">Temperatura</option>
        <option value="boosted">Potenciado</option>
      </select>
    </div>
  )
}
```

### FilterPanelNests.tsx

```tsx
import { useStore } from '../../store/useStore'

export default function FilterPanelNests() {
  const { nestTypeFilter, nestSortBy } = useStore(s => ({
    nestTypeFilter: s.nestTypeFilter,
    nestSortBy: s.nestSortBy,
  }))
  const { setNestTypeFilter, setNestSortBy } = useStore()

  return (
    <div className="filter-panel filter-panel-nests">
      {nestTypeFilter && (
        <button 
          className="filter-reset"
          onClick={() => { setNestTypeFilter(null); setNestSortBy('name') }}
        >
          ↻ Restablecer
        </button>
      )}

      <select value={nestTypeFilter || ''} onChange={e => setNestTypeFilter(e.target.value || null)}>
        <option value="">Tipo Pokémon</option>
        {/* ... opciones de tipo */}
      </select>

      <select value={nestSortBy || 'name'} onChange={e => setNestSortBy(e.target.value)}>
        <option value="name">Nombre</option>
        <option value="type">Tipo</option>
        <option value="spawnRate">Spawn Rate</option>
      </select>
    </div>
  )
}
```

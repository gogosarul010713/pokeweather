## Historia de Usuario

> Como usuario, quiero que en modo Todo la leyenda muestre ambas secciones de forma organizada **para** no saturar el mapa.

---

## Criterios de Aceptación

- [ ] La leyenda tiene **dos secciones acordeón:** `Clima` y `Nidos`
- [ ] Cada sección se expande/colapsa de forma **independiente**
- [ ] **Sección Clima:** sin cambios respecto a la leyenda actual
- [ ] **Sección Nidos:** misma estructura definida en US-815
- [ ] La leyenda completa es colapsable en su totalidad
- [ ] Estado de expansión/colapso se **persiste** en localStorage

## Código de Ejemplo

### CombinedLegend.tsx

```tsx
import { useState, useEffect } from 'react'
import ClimateLegend from './ClimateLegend'
import NestLegend from './NestLegend'

export default function CombinedLegend() {
  const [expandClima, setExpandClima] = useState(() => 
    localStorage.getItem('pwe-legendClima') !== 'false'
  )
  const [expandNests, setExpandNests] = useState(() => 
    localStorage.getItem('pwe-legendNests') !== 'false'
  )

  useEffect(() => {
    localStorage.setItem('pwe-legendClima', String(expandClima))
  }, [expandClima])

  useEffect(() => {
    localStorage.setItem('pwe-legendNests', String(expandNests))
  }, [expandNests])

  return (
    <div className="combined-legend">
      <div className="legend-section">
        <button 
          className="legend-header"
          onClick={() => setExpandClima(!expandClima)}
        >
          <span>{expandClima ? '▼' : '▶'}</span>
          <span>Clima</span>
        </button>
        {expandClima && <ClimateLegend />}
      </div>

      <div className="legend-section">
        <button 
          className="legend-header"
          onClick={() => setExpandNests(!expandNests)}
        >
          <span>{expandNests ? '▼' : '▶'}</span>
          <span>Nidos</span>
        </button>
        {expandNests && <NestLegend />}
      </div>
    </div>
  )
}
```

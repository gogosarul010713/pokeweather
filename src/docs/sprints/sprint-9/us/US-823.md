# 📋 US-823 — Layer Selector en Header (Clima/Nidos)

**Sprint:** 9 (Sesión 2 - Rediseño)  
**Story Points:** 2 SP  
**Prioridad:** P0  
**Status:** ⏳ Pendiente  
**Dependencias:** US-820 (requiere sidebar sin tabs)  
**Sesión:** 2/3

---

## Historia de Usuario

> Como usuario, quiero seleccionar entre capas de mapa (Clima / Nidos) directamente en el header **para** cambiar rápidamente entre vistas sin navegar el sidebar.

---

## Criterios de Aceptación

**Selector visual:**
- [ ] Ubicación: **Header, lado derecho** (cerca de otros controles)
- [ ] Dos botones/opciones: `Clima` y `Nidos`
- [ ] Estado visual claro: uno activo (subrayado, color, etc.), otro inactivo
- [ ] Icono + etiqueta (ej: `🌡️ Clima` y `🏠 Nidos`) O solo etiqueta

**Comportamiento:**
- [ ] Click en `Clima`: activa capa Clima
  - [ ] Sidebar renderiza lista Clima + filtros Clima
  - [ ] Mapa renderiza pins Clima (no Nidos)
  - [ ] Leyenda muestra solo Clima
- [ ] Click en `Nidos`: activa capa Nidos
  - [ ] Sidebar renderiza lista Nidos + filtros Nidos
  - [ ] Mapa renderiza pins Nidos (no Clima)
  - [ ] Leyenda muestra solo Nidos
- [ ] No hay modo "Todo" — solo uno activo a la vez
- [ ] Cambiar de capa resetea filtros (no persistir entre capas)
- [ ] Transición suave entre capas

**State:**
- [ ] `activeTab` (o renombrar a `activeLayer`) controla qué se renderiza
- [ ] Valor: `'clima'` o `'nidos'`
- [ ] Persistencia: localStorage (`pwe-activeLayer`)

## Código de Ejemplo

### LayerSelector.tsx

```tsx
import { useStore } from '../../store/useStore'

export default function LayerSelector() {
  const activeTab = useStore(s => s.activeTab)
  const setActiveTab = useStore(s => s.setActiveTab)

  return (
    <div className="layer-selector">
      <button
        className={`layer-btn ${activeTab === 'clima' ? 'active' : ''}`}
        onClick={() => setActiveTab('clima')}
        aria-pressed={activeTab === 'clima'}
      >
        <span className="layer-icon">🌡️</span>
        <span className="layer-label">Clima</span>
      </button>

      <button
        className={`layer-btn ${activeTab === 'nidos' ? 'active' : ''}`}
        onClick={() => setActiveTab('nidos')}
        aria-pressed={activeTab === 'nidos'}
      >
        <span className="layer-icon">🏠</span>
        <span className="layer-label">Nidos</span>
      </button>
    </div>
  )
}
```

### useStore.ts (snippet)

```tsx
type PokeweatherStore = {
  // Layers
  activeTab: 'clima' | 'nidos'
  setActiveTab: (tab: 'clima' | 'nidos') => void
  
  // ... resto de state
}

export const useStore = create<PokeweatherStore>((set) => {
  // Cargar state inicial desde localStorage
  const savedLayer = localStorage.getItem('pwe-activeLayer') || 'clima'
  
  return {
    activeTab: savedLayer as 'clima' | 'nidos',
    setActiveTab: (tab) => {
      localStorage.setItem('pwe-activeLayer', tab)
      set({ activeTab: tab })
    },
    
    // ... resto de actions
  }
})
```

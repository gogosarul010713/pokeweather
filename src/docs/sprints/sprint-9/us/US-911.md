## Historia de Usuario

> Como jugador, quiero que el contador de migracion de nidos se actualice automaticamente cada 14 dias sin que nadie tenga que editar codigo, para que la informacion siempre refleje el ciclo vigente de Niantic.

---

## Contexto tecnico

La implementacion actual usa una constante estatica en `src/config/nestMigration.ts`:

```ts
export const NEXT_MIGRATION = '2026-08-06T10:00:00Z'
```

Esta fecha ya vencio (2026-08-20). Como consecuencia:
- `isConfirmedActive` es `false` para todos los nidos, aunque `confirmed: true`
- El badge `?` se muestra en todos los nidos
- El MigrationBanner muestra "Migro hace Xh - Sin confirmar" permanentemente

Niantic realiza migraciones cada 14 dias desde una fecha anchor conocida. La logica debe calcular el proximo evento del ciclo en lugar de depender de una fecha manual.

---

## Criterios de Aceptacion

### Calculo del ciclo

- [x] Existe una fecha anchor fija en la configuracion: `MIGRATION_ANCHOR = '2026-08-06T10:00:00Z'`
- [x] Existe un intervalo fijo en la configuracion: `MIGRATION_CYCLE_DAYS = 14`
- [x] La funcion `getNextMigration(now: number): Date` calcula la proxima fecha de migracion sumando multiplos de 14 dias al anchor hasta encontrar la primera fecha futura respecto a `now`
- [x] `getNextMigration` es una funcion pura -- no llama a `Date.now()` internamente; recibe `now` como parametro
- [x] Si `now` esta exactamente en el anchor, `getNextMigration` retorna `anchor + 14d`

### isConfirmedActive

- [x] `isConfirmedActive` se evalua como `nest.confirmed && now < getNextMigration(now).getTime()`
- [x] Con el ciclo vigente (2026-08-20), la proxima migracion calculada es 2026-09-03T10:00:00Z, por lo que nidos con `confirmed: true` muestran badge `✓` verde
- [x] Cuando `now` supere 2026-09-03T10:00:00Z, el sistema calcula automaticamente 2026-09-17T10:00:00Z como proxima migracion sin cambios en el codigo

### MigrationBanner y countdown

- [x] `getMigrationStatus` recibe la fecha calculada por `getNextMigration(now)` -- no la constante estatica
- [x] El countdown muestra "Migra en Xd Yh" cuando la proxima migracion es futura
- [x] El countdown se actualiza reactivamente via `store.now` sin reload

### Sin regresion

- [x] La firma de `getMigrationStatus(nextMigration: string, now: number)` no cambia o -- si cambia -- todos los llamadores son actualizados
- [x] NestPopup, NestDetail y NestCard reciben la fecha calculada, no la constante importada directamente
- [x] El archivo `src/config/nestMigration.ts` sigue existiendo pero exporta el anchor y el intervalo, no una fecha absoluta vencida

## Notas

- El anchor `2026-08-06T10:00:00Z` es un dato historico verificado -- no debe cambiar. Si Niantic cambia el ciclo, se agrega un nuevo anchor con su fecha de vigencia (fuera del scope de esta US).
- El intervalo es exactamente `14 * 24 * 60 * 60 * 1000` ms. No ajustar por horario de verano.
- No se requiere llamada a API ni persistencia -- todo es calculo en memoria sobre `store.now`.

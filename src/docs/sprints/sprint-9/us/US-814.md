---

## Historia de Usuario

> Como usuario, quiero que la barra de filtros cambie según el tab activo **para** ver solo los filtros relevantes.

---

## Criterios de Aceptación

**Cuando tab Clima está activo:**
- [ ] Botón: `Todas`
- [ ] Dropdown: `Clima` (soleado, lluvia, viento, etc.)
- [ ] Dropdown: `Tipo` (tipo de Pokémon potenciado)
- [ ] Dropdown: `Ordenar por` → Temperatura, Pokémon potenciado
- [ ] (sin cambios respecto a comportamiento actual)

**Cuando tab Nidos está activo:**
- [ ] Dropdown Multi-select: `Tipo` (tipo de Pokémon del nido) — seleccionar múltiples tipos
- [ ] SortDropdown: `Ordenar por` → Nombre, Tipo, Spawn Rate (asc/desc con iconos, igual que Clima)
- [ ] Botón Restablecer (limpiar filtros) — solo si hay filtros activos

**Reglas generales:**
- [ ] La barra de filtros se **reemplaza completamente** al cambiar de tab
- [ ] Los filtros operan solo sobre la lista del sidebar, no sobre los pines del mapa
- [ ] Cuando `Todo` está activo, la barra de filtros se **bloquea con overlay** — BUT **TabControl debe estar activo** para poder volver a otro tab y desbloquear
- [ ] Al cambiar de tab, los filtros se resetean (no persistir entre tabs)
- [ ] Transiciones suaves (fade-out/fade-in)
- [ ] Botón "Todos" en Nidos: NO existe. Solo existe en Clima (limpiar es automático con botón icon ↻)

---

## 🏗️ Decisión Arquitectónica (Sesión 2)

**Ubicación:** FilterBar se queda en **Header** (estado actual)
**Cambio:** Panel se reemplaza **totalmente** según `activeTab`

| Tab | Comportamiento |
|-----|---|
| **Clima** | Renderiza filtros clima actuales (región, condición, tipo, ordenar) |
| **Nidos** | Renderiza filtros nidos (tipo pokémon, ordenar) |
| **Todo** | FilterBar bloqueado con Overlay + mensaje "No se puede filtrar en modo Todo" |

## Código de Ejemplo

### FilterPanel.tsx (Wrapper en Header)

```tsx
import { useStore } from '../../store/useStore'
import FilterPanelClima from './FilterPanelClima'
import FilterPanelNests from './FilterPanelNests'
import Overlay from '../UI/Overlay'

export default function FilterPanel() {
  const activeTab = useStore(s => s.activeTab)
  const isBlocked = activeTab === 'todo'

  return (
    <div className="filter-panel-wrapper" style={{ position: 'relative' }}>
      {activeTab === 'clima' && <FilterPanelClima />}
      {activeTab === 'nidos' && <FilterPanelNests />}
      
      {isBlocked && (
        <Overlay 
          isActive={true} 
          message="No se puede filtrar cuando Todo está activo"
          zIndex={50}
        />
      )}
    </div>
  )
}
```

### FilterPanelNests.tsx (Nuevo)

```tsx
import { useStore } from '../../store/useStore'
import { POKEMON_TYPES } from '../../config/pokemonTypes'

export default function FilterPanelNests() {
  const nestTypeFilter = useStore(s => s.nestTypeFilter)
  const setNestTypeFilter = useStore(s => s.setNestTypeFilter)
  const nestSortBy = useStore(s => s.nestSortBy)
  const setNestSortBy = useStore(s => s.setNestSortBy)

  return (
    <div className="filter-panel-nests">
      <button 
        className="filter-btn"
        onClick={() => { 
          setNestTypeFilter(null)
          setNestSortBy('name')
        }}
      >
        Todos
      </button>
      
      <select 
        value={nestTypeFilter || ''} 
        onChange={e => setNestTypeFilter(e.target.value || null)}
        className="filter-select"
      >
        <option value="">Tipo Pokémon</option>
        {POKEMON_TYPES.map(t => (
          <option key={t} value={t}>{t}</option>
        ))}
      </select>

      <select 
        value={nestSortBy} 
        onChange={e => setNestSortBy(e.target.value as any)}
        className="filter-select"
      >
        <option value="name">Nombre</option>
        <option value="type">Tipo</option>
        <option value="spawnRate">Spawn Rate</option>
      </select>
    </div>
  )
}
```

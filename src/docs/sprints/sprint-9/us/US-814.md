# 📋 US-814 — Filtros Contextuales por Tab

**Sprint:** 9 (Sesión 2)  
**Story Points:** 3 SP  
**Prioridad:** P0  
**Status:** ⏳ Pendiente  
**Dependencias:** US-811, US-818  
**Sesión:** 2/3

---

## Historia de Usuario

> Como usuario, quiero que la barra de filtros cambie según el tab activo **para** ver solo los filtros relevantes.

---

## Criterios de Aceptación

**Cuando tab Clima está activo:**
- [ ] Botón: `Todas`
- [ ] Dropdown: `Clima` (soleado, lluvia, viento, etc.)
- [ ] Dropdown: `Tipo` (tipo de Pokémon potenciado)
- [ ] Dropdown: `Ordenar por` → Temperatura, Pokémon potenciado
- [ ] (sin cambios respecto a comportamiento actual)

**Cuando tab Nidos está activo:**
- [ ] Botón: `Todos`
- [ ] Dropdown: `Tipo` (tipo de Pokémon del nido)
- [ ] Dropdown: `Ordenar por` → Tipo de Pokémon, Nombre, Spawn Rate (si disponible)

**Reglas generales:**
- [ ] La barra de filtros se **reemplaza completamente** al cambiar de tab
- [ ] Los filtros operan solo sobre la lista del sidebar, no sobre los pines del mapa
- [ ] Cuando `Todo` está activo, la barra de filtros se **bloquea con overlay** (ver US-817)
- [ ] Al cambiar de tab, los filtros se resetean (no persistir entre tabs)
- [ ] Transiciones suaves (fade-out/fade-in)

## Código de Ejemplo

### FilterBar.tsx (Wrapper)

```tsx
import { useStore } from '../../store/useStore'
import FilterBarClima from './FilterBar/FilterBarClima'
import FilterBarNests from './FilterBar/FilterBarNests'
import Overlay from './Overlay'

export default function FilterBar() {
  const activeTab = useStore(s => s.activeTab)
  const isBlocked = activeTab === 'todo'

  return (
    <div className="filter-bar-wrapper">
      {activeTab === 'clima' && <FilterBarClima />}
      {activeTab === 'nidos' && <FilterBarNests />}
      
      <Overlay isActive={isBlocked} message="Filtros bloqueados en modo Todo" />
    </div>
  )
}
```

### FilterBarNests.tsx

```tsx
import { useStore } from '../../../store/useStore'

export default function FilterBarNests() {
  const typeFilter = useStore(s => s.nestTypeFilter)
  const setTypeFilter = useStore(s => s.setNestTypeFilter)
  const sortBy = useStore(s => s.nestSortBy)
  setSortBy = useStore(s => s.setNestSortBy)

  const TYPES = ['All', 'Water', 'Fire', 'Grass', 'Electric', ...]

  return (
    <div className="filter-bar">
      <button onClick={() => { setTypeFilter(null); setSortBy('name') }}>
        Todos
      </button>
      
      <select value={typeFilter || ''} onChange={e => setTypeFilter(e.target.value || null)}>
        <option value="">Tipo</option>
        {TYPES.map(t => <option key={t} value={t}>{t}</option>)}
      </select>

      <select value={sortBy} onChange={e => setSortBy(e.target.value as any)}>
        <option value="name">Nombre</option>
        <option value="type">Tipo Pokémon</option>
        <option value="spawnRate">Spawn Rate</option>
      </select>
    </div>
  )
}
```

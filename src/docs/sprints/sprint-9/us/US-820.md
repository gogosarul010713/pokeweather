# 📋 US-820 — Remover TabControl del Sidebar

**Sprint:** 9 (Sesión 2 - Rediseño)  
**Story Points:** 2 SP  
**Prioridad:** P0  
**Status:** ⏳ Pendiente  
**Dependencias:** US-811 (requiere TabControl existente)  
**Sesión:** 2/3

---

## Historia de Usuario

> Como usuario, quiero que desaparezca el control de tabs del sidebar **para** que el mapa sea el elemento principal y el selector de capas esté en el header.

---

## Criterios de Aceptación

- [ ] TabControl (`src/components/Sidebar/TabControl.tsx`) se **elimina completamente** del Sidebar
- [ ] Sidebar renderiza **solo el contenido activo** (lista Clima o lista Nidos)
- [ ] Contenedor del sidebar se simplifica: solo `.sb-content` (sin `.sb-tabs`)
- [ ] Layout del sidebar **ocupa menos espacio** (sin row de tabs)
- [ ] Build compila sin errores
- [ ] No hay regresión en funcionamiento de lista/filtros

---

## Archivos a Crear/Modificar

### Eliminar:
1. **`src/components/Sidebar/TabControl.tsx`** ❌

### Modificar:
1. **`src/components/Sidebar/Sidebar.tsx`**
   - Remover renderizado de `<TabControl />`
   - Remover className `.sb-tabs`
   - Simplificar estructura (mantener solo `.sb-content`)

### Verificar (sin cambios esperados):
1. `src/store/useStore.ts` — `activeTab` permanece (usado por Header layer selector)
2. `src/components/Header/Header.tsx` — No afectado

---

## Código de Ejemplo

### Antes (Sidebar.tsx)
```tsx
<div className="sidebar">
  <div className="sb-tabs">
    <TabControl />
  </div>
  <div className="sb-content">
    {activeTab === 'clima' && <LocationFeed />}
    {activeTab === 'nidos' && <NestFeed />}
  </div>
</div>
```

### Después (Sidebar.tsx)
```tsx
<div className="sidebar">
  <div className="sb-content">
    {activeTab === 'clima' && <LocationFeed />}
    {activeTab === 'nidos' && <NestFeed />}
  </div>
</div>
```

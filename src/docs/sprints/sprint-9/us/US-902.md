# US-902 — Lazy Load TestingTools Components

**Sprint:** 9  
**Priority:** P1  
**Story Points:** 3  
**Status:** 🎯 PLANEADO  
**Sesiones:** 1-2

---

## Problema

TestingTools (ClassificationReportModal, ReportsPanel, PrecisionMetrics) carga siempre, aunque usuario no lo abre frecuentemente.

---

## Solución

Lazy load TestingTools con React.lazy() + Suspense + error boundary.

---

## Subtareas

### Subtarea 1: Lazy Load Setup (2 SP)
```typescript
// Antes:
import ClassificationReportModal from './ClassificationReportModal';

// Después:
const ClassificationReportModal = React.lazy(
  () => import('./ClassificationReportModal')
);
```

**Componentes:**
- ClassificationReportModal (358 líneas)
- ReportsPanel (252 líneas)
- PrecisionMetrics (506 líneas)

**Infrastructure:**
- Suspense wrapper
- Error boundary
- Loading state

## 📌 Problema

**Contexto:** Con Firebase Report guardando la verdad del clima real, tres tabs de Testing Tools ya no son necesarios:
1. **Historial (📊):** Validación manual de snapshots → Ya lo hace Firebase Report
2. **Caché (🔧):** Inspector visual del cache → Ya lo hace Firebase Firestore
3. **Métricas (📈):** Cálculo de precisión local → Se trasladará a Dashboard externo (Metabase)

Mantener estos tabs es **deuda técnica** que aumenta bundle size (~120 KB innecesarios).

---

## 🎯 Solución

Refactorizar `TestingTools.tsx` para:
1. ✅ **Eliminar 3 tabs:** Historial, Caché, Métricas
2. ✅ **Mantener 1 tab:** Reportes (⚠️ Validación de clima incorrecto)
3. ✅ **Limpiar servicios obsoletos:** Funciones no críticas de `weatherHistoryService`
4. ✅ **Reducir bundle:** -120 KB

## 📚 Evidencia: Por qué se eliminan

### ❌ Historial (HistoryGrid) — Ya no necesario

**Razón:** Firebase Report es la verdad oficial

| Antes | Ahora |
|-------|-------|
| HistoryGrid mostraba snapshots guardados en IndexedDB | ClassificationReportModal (ReportsPanel) muestra reportes guardados en Firestore |
| Usuario llenaba manualmente `actualCondition` en snapshots | Usuario verifica clima incorrecto vía Report modal |
| **Conclusión:** Historial es UI de transición, Report es la realidad | |

**Documentación:** Ver [`EVIDENCE-Historial.md`](./EVIDENCE-Historial.md)

### ❌ Caché (CachePanel) — Ya no necesario

**Razón:** Firebase Firestore replica esa información

| Antes | Ahora |
|-------|-------|
| CachePanel inspeccionaba IndexedDB visualmente | Firestore muestra todos los weather_catalogs en consola Firebase |
| Útil para debugging local | Innecesario con cloud persistence |
| **Conclusión:** Caché local es detalle de implementación | |

**Documentación:** Ver [`EVIDENCE-Cache.md`](./EVIDENCE-Cache.md)

### ❌ Métricas (PrecisionMetrics) — Se trasladó

**Razón:** Dashboard Metabase es superior para investigación

| Antes | Ahora |
|-------|-------|
| PrecisionMetrics calculaba precisión local en React | Dashboard Metabase conecta Firestore y calcula en SQL |
| Visualización básica (tablas) | Visualización avanzada (gráficos, filtros, comparativas) |
| Solo datos en memoria | Datos históricos + análisis temporal |
| **Conclusión:** Dashboard externo es mejor herramienta para investigación | |

**Documentación:** Ver [`EVIDENCE-Metrics.md`](./EVIDENCE-Metrics.md)

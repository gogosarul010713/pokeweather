# US-912 -- Quitar estilo disabled en nidos no verificados

**Sprint:** 9
**Story Points:** 1
**Prioridad:** Media
**Status:** Completada
**Dependencias:** US-818 (NestCard, estilos .nc-root.unconfirmed)

---

## Historia de Usuario

> Como jugador, quiero ver todos los nidos con apariencia normal independientemente de si estan verificados o no, para poder evaluar opciones sin que el estilo visual me induzca a descartar nidos potencialmente validos.

---

## Contexto tecnico

US-818 implemento estilos "disabled" en NestCard cuando `!isConfirmedActive`:

```css
.nc-root.unconfirmed { opacity: 0.7; }
.nc-root.unconfirmed .nc-sprite { filter: grayscale(1) opacity(0.5); }
.nc-spawn-badge.unconf { background: rgba(128,128,128,.10); color: var(--text-secondary); opacity: .7; }
```

La clase `unconfirmed` se aplica cuando el nido no esta confirmado o la migracion vencio. Problema: los usuarios interpretan el estilo "disabled" como "nido no disponible", no como "no verificado por la comunidad".

El badge `✓`/`?` ya comunica el estado de verificacion de forma suficiente.

---

## Criterios de Aceptacion

### Estilos a eliminar

- [x] La regla `.nc-root.unconfirmed { opacity: 0.7; }` es eliminada
- [x] La regla `.nc-root.unconfirmed .nc-sprite { filter: grayscale(1) opacity(0.5); }` es eliminada -- sprite a color completo siempre
- [x] La regla `.nc-spawn-badge.unconf` que aplica `opacity: .7` y color gris es eliminada -- badge de spawn con mismo estilo siempre
- [x] La clase CSS `unconfirmed` puede permanecer en el DOM pero sin efectos visuales de degradacion

### Badge de verificacion

- [x] Badge `✓` verde sigue apareciendo cuando `isConfirmedActive = true`
- [x] Badge `?` gris sigue apareciendo cuando `isConfirmedActive = false`
- [x] No se agrega ninguna otra señal visual de degradacion para nidos no verificados

### Sin regresion

- [x] NestPopup: si tiene estilos equivalentes para estado no confirmado, tambien se eliminan
- [x] NestDetail: idem
- [x] Hover y estado selected de NestCard no se ven afectados
- [x] Interactividad del nido (click para flyTo + popup) no cambia

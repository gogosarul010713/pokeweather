# 📋 US-817 — Modo Todo: Overlay Sidebar y Filtros

**Sprint:** 9 (Sesión 1)

## Historia de Usuario

> Como usuario, quiero que al activar el tab Todo se me comunique claramente que sidebar y filtros no están disponibles en ese modo **para** no confundirme al intentar interactuar con ellos.

---

## Criterios de Aceptación

- [ ] Al cambiar a `Todo` se muestra un **toast informativo:**
  - Texto: _"Mostrando Clima y Nidos simultáneamente en el mapa"_
  - Duración: 3-4 segundos
  - Dismissible: click o auto-desaparición
- [ ] El sidebar muestra un **overlay de opacidad ~40%** — el contenido se intuye pero no es interactuable
- [ ] Sobre el overlay aparece un **texto centrado:**
  - 🔒 _"Activa Clima o Nidos para explorar la lista y filtros"_
  - Font: 14px, peso 500, color primario
  - Vertical y horizontalmente centrado
- [ ] El cursor cambia a `not-allowed` al intentar hacer hover en el área bloqueada
- [ ] La barra de filtros recibe el mismo tratamiento: overlay + cursor no-permitido
- [ ] Al cambiar a `Clima` o `Nidos`: sidebar y filtros se reactivan **inmediatamente** (sin delay)
- [ ] El overlay puede desaparecer/reaparecer sin afectar el scroll position

## Código de Ejemplo

### Overlay.tsx

```tsx
interface OverlayProps {
  isActive: boolean
  message: React.ReactNode
  zIndex?: number
}

export default function Overlay({ isActive, message, zIndex = 100 }: OverlayProps) {
  if (!isActive) return null

  return (
    <div className="overlay" style={{ zIndex }}>
      <div className="overlay-background" />
      <div className="overlay-message">
        <div className="overlay-icon">🔒</div>
        <p>{message}</p>
      </div>
    </div>
  )
}
```

### Toast.tsx

```tsx
import { useState, useEffect } from 'react'

interface ToastProps {
  message: string
  duration?: number
  onDismiss?: () => void
}

export default function Toast({ message, duration = 3000, onDismiss }: ToastProps) {
  const [isVisible, setIsVisible] = useState(true)

  useEffect(() => {
    const timer = setTimeout(() => {
      setIsVisible(false)
      onDismiss?.()
    }, duration)

    return () => clearTimeout(timer)
  }, [duration, onDismiss])

  if (!isVisible) return null

  return (
    <div className="toast">
      <p>{message}</p>
      <button onClick={() => setIsVisible(false)}>✕</button>
    </div>
  )
}
```

### Integración en Sidebar.tsx

```tsx
import Overlay from '../UI/Overlay'

export default function Sidebar({ cities }: SidebarProps) {
  const activeTab = useStore(s => s.activeTab)
  const isBlocked = activeTab === 'todo'

  return (
    <div className="sb-root">
      {/* Existing sidebar content */}
      
      {/* Overlay cuando todo está activo */}
      <Overlay 
        isActive={isBlocked} 
        message="Activa Clima o Nidos para explorar la lista y filtros"
      />
    </div>
  )
}
```

### Integración en App.tsx

```tsx
import Toast from './components/UI/Toast'

export default function App() {
  const [showToast, setShowToast] = useState(false)
  const [previousTab, setPreviousTab] = useState<'clima' | 'nidos' | 'todo'>('clima')
  const activeTab = useStore(s => s.activeTab)

  useEffect(() => {
    if (activeTab === 'todo' && previousTab !== 'todo') {
      setShowToast(true)
    }
    setPreviousTab(activeTab)
  }, [activeTab, previousTab])

  return (
    <>
      {/* Existing JSX */}
      
      {showToast && (
        <Toast 
          message="Mostrando Clima y Nidos simultáneamente en el mapa"
          onDismiss={() => setShowToast(false)}
        />
      )}
    </>
  )
}
```

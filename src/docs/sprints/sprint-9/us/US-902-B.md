## 📌 Contexto

**Problema de Investigación:**  
¿Toma Pokémon GO el pronóstico de una **hora específica** de las 12 horas predichas, o usa un algoritmo diferente?

**Hipótesis:**  
Si Pokémon GO selecciona siempre, por ejemplo, la hora 1, 6, o 12 del pronóstico, podríamos optimizar el algoritmo de clasificación al enfocarnos en esa "ventana".

**Cómo investigar:**  
Crear un dashboard que compare:
1. **Pronósticos 12h:** Cada hora predicha por AccuWeather
2. **Clima Real:** Lo que el usuario reporta vía Report modal
3. **Coincidencias:** Qué horas del pronóstico coincidieron con el clima real
4. **Patrón:** ¿Siempre la misma hora coincide?

---

## 🎯 Solución

Crear **Dashboard Metabase** (herramienta gratuita, self-hosted) conectado a Firestore que:

1. **Ingesta datos** de Firestore (ForecastDoc + ClassificationReport)
2. **Calcula coincidencias** (pronóstico vs clima real)
3. **Visualiza patrones** (gráficos temporales, histogramas)
4. **Filtra por** ciudad, fecha, hora, condición

### Subtarea 3: Crear Queries SQL (2 SP)

**Objetivo:** Queries que calculen coincidencias y patrones

**Query 1: Precisión Global**
```sql
SELECT
  COUNT(*) as total_reports,
  SUM(CASE WHEN match THEN 1 ELSE 0 END) as accurate,
  ROUND(SUM(CASE WHEN match THEN 1 ELSE 0 END) * 100.0 / COUNT(*), 1) as accuracy_pct
FROM classification_reports cr
JOIN forecast_snapshots fs ON cr.city_id = fs.city_id
  AND cr.date_hour = fs.date_hour
WHERE cr.timestamp >= DATE_SUB(NOW(), INTERVAL 7 DAY)
```

**Query 2: Coincidencias Históricas (Hora Específica)**
```sql
SELECT
  fs.forecast_hour_offset,  -- 1, 2, ..., 12 (cuántas horas adelante)
  COUNT(*) as total_predictions,
  SUM(CASE WHEN fs.prediction = cr.should_be THEN 1 ELSE 0 END) as matches,
  ROUND(SUM(CASE WHEN fs.prediction = cr.should_be THEN 1 ELSE 0 END) * 100.0 / COUNT(*), 1) as match_pct
FROM forecast_snapshots fs
JOIN classification_reports cr ON ...
GROUP BY fs.forecast_hour_offset
ORDER BY match_pct DESC
```
→ **Resultado esperado:** Si una hora siempre tiene 90%+ matches, ¡encontramos el slot!

**Query 3: Por Condición**
```sql
SELECT
  cr.should_be as actual_condition,
  fs.forecast_hour_offset,
  COUNT(*) as predictions,
  SUM(CASE WHEN fs.prediction = cr.should_be THEN 1 ELSE 0 END) as matches,
  ROUND(SUM(...) * 100.0 / COUNT(*), 1) as accuracy_pct
FROM ...
GROUP BY cr.should_be, fs.forecast_hour_offset
ORDER BY actual_condition, forecast_hour_offset
```

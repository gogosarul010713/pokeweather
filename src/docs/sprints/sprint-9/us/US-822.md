# 📋 US-822 — Sidebar Colapsable + Hamburger

**Sprint:** 9 (Sesión 2 - Rediseño)  
**Story Points:** 3 SP  
**Prioridad:** P0  
**Status:** ⏳ Pendiente  
**Dependencias:** US-820, US-821  
**Sesión:** 2/3

---

## Historia de Usuario

> Como usuario, quiero poder colapsar el sidebar con un botón hamburger **para** que el mapa ocupe más espacio en pantalla.

---

## Criterios de Aceptación

**Estado del sidebar:**
- [ ] Sidebar tiene un estado: `expanded` (true) o `collapsed` (false)
- [ ] Estado se persiste en localStorage (`pwe-sidebarExpanded`)
- [ ] Default: `expanded: true` (abre por defecto)

**Botón hamburger:**
- [ ] Icono ☰ (hamburger) en la **esquina superior izquierda** del sidebar
- [ ] Al clickear toggle: sidebar collapse/expand
- [ ] Icono cambia a X cuando colapsado, ☰ cuando expandido
- [ ] Siempre visible (fixed position en top-left del sidebar)

**Comportamiento en collapse:**
- [ ] Sidebar se desplaza hacia la izquierda fuera de pantalla
- [ ] Mapa expande para ocupar todo el ancho disponible
- [ ] Transición suave (300ms) con transform
- [ ] Hamburger permanece visible (z-index alto)

**Comportamiento en expand:**
- [ ] Sidebar vuelve a su posición original
- [ ] Mapa vuelve a su ancho anterior
- [ ] Transición suave (300ms)

**Responsive:**
- [ ] En mobile (< 768px): hamburger siempre visible
- [ ] En desktop: hamburger opcional (o siempre visible según diseño)
- [ ] Sidebar width permanece igual en expand/collapse

## Código de Ejemplo

### SidebarToggle.tsx

```tsx
import { useState, useEffect } from 'react'

interface Props {
  isExpanded: boolean
  onToggle: () => void
}

export default function SidebarToggle({ isExpanded, onToggle }: Props) {
  return (
    <button 
      className="sidebar-toggle"
      onClick={onToggle}
      aria-label={isExpanded ? 'Collapse sidebar' : 'Expand sidebar'}
    >
      <span className="sidebar-toggle-icon">
        {isExpanded ? '☰' : '✕'}
      </span>
    </button>
  )
}
```

### Sidebar.tsx

```tsx
import { useState, useEffect } from 'react'
import SidebarToggle from './SidebarToggle'
import FilterPanel from './FilterPanel'

export default function Sidebar() {
  const [isExpanded, setIsExpanded] = useState(() => {
    const saved = localStorage.getItem('pwe-sidebarExpanded')
    return saved !== null ? JSON.parse(saved) : true
  })

  useEffect(() => {
    localStorage.setItem('pwe-sidebarExpanded', JSON.stringify(isExpanded))
  }, [isExpanded])

  return (
    <div className={`sidebar ${isExpanded ? '' : 'sidebar--collapsed'}`}>
      <SidebarToggle 
        isExpanded={isExpanded} 
        onToggle={() => setIsExpanded(!isExpanded)}
      />
      
      <div className="sb-content">
        <FilterPanel />
        {/* Lista Clima o Nidos */}
      </div>
    </div>
  )
}
```

## Historia de Usuario

> Como jugador, quiero ver en el sidebar una lista de lugares con informacion resumida de todas las capas activas, para poder comparar opciones y decidir a donde ir sin tener que hacer clic en cada pin del mapa.

> Caso de uso especifico nidos: quiero ver el sprite del pokemon, si el nido esta confirmado, cuanto SD da, el spawn rate, y cuanto tiempo me queda antes de que migre.

## Criterios de Aceptacion

### Feed general
- [ ] `LocationFeed` muestra lugares con datos en cualquier capa activa (no solo clima)
- [ ] Cada `LocationCard` muestra tags solo de las capas que estan activas Y que ese lugar tiene datos
- [ ] Si solo Clima esta activo: cards muestran weather + tipos potenciados
- [ ] Si solo Nidos esta activo: cards muestran NestCard con sprite, nombre, confirmacion, tipos
- [ ] Si ambos activos: cards muestran ambos bloques de info
- [ ] Al hacer clic en una card: el mapa vuela a esa ubicacion y el pin se selecciona
- [ ] Al hacer clic en un pin del mapa: la card correspondiente se selecciona y el sidebar hace scroll hasta ella
- [ ] `LocationDetail` (panel de detalle) muestra secciones por capa activa
- [ ] Si ninguna capa esta activa: feed muestra empty state "Activa una capa para ver resultados"
- [ ] El conteo de resultados en el header del feed refleja solo los lugares visibles

## Código de Ejemplo

### `src/components/Sidebar/LocationFeed.tsx` — lógica unificada

```tsx
import { useStore } from '../../store/useStore'
import { useMemo } from 'react'

export function LocationFeed() {
  const {
    activeLayers,
    cities,           // datos de clima — nombre real puede variar
    nests,            // datos de nidos
    selectedCityId,
    selectedNest,
    badgeFilter,
    nestTypeFilter,
  } = useStore()

  const feedItems = useMemo(() => {
    // Construir set de IDs de lugares con datos en capas activas
    const placeMap = new Map<string, FeedItem>()

    if (activeLayers.clima) {
      cities.forEach(city => {
        placeMap.set(city.id, {
          id: city.id,
          name: city.name,
          location: city.country,
          lat: city.lat,
          lon: city.lon,
          climaData: city,
          nidoData: null,
        })
      })
    }

    if (activeLayers.nidos) {
      nests.forEach(nest => {
        const existing = placeMap.get(nest.placeId)
        if (existing) {
          // Mismo lugar tiene clima y nido — enriquecer
          existing.nidoData = nest
        } else {
          placeMap.set(nest.placeId, {
            id: nest.placeId,
            name: nest.name,
            location: nest.city,
            lat: nest.lat,
            lon: nest.lon,
            climaData: null,
            nidoData: nest,
          })
        }
      })
    }

    let items = Array.from(placeMap.values())

    // Aplicar filtros
    if (activeLayers.clima && badgeFilter && badgeFilter !== 'all') {
      items = items.filter(i => i.climaData?.weather === badgeFilter || !i.climaData)
    }

    if (activeLayers.nidos && nestTypeFilter && nestTypeFilter !== 'all') {
      items = items.filter(i =>
        i.nidoData?.pokemon.some(p => p.type === nestTypeFilter) || !i.nidoData
      )
    }

    return items
  }, [activeLayers, cities, nests, badgeFilter, nestTypeFilter])

  if (feedItems.length === 0) {
    return (
      <div style={{ /* empty state styles */ }}>
        {(!activeLayers.clima && !activeLayers.nidos)
          ? 'Activa una capa para ver resultados'
          : 'Sin resultados. Prueba otros filtros.'}
      </div>
    )
  }

  return (
    <div style={{ flex: 1, overflowY: 'auto' }}>
      {feedItems.map(item => (
        <LocationCard
          key={item.id}
          item={item}
          isSelected={selectedCityId === item.id || selectedNest?.placeId === item.id}
        />
      ))}
    </div>
  )
}
```

### `src/components/Sidebar/LocationCard.tsx` — tags por capa

```tsx
interface LocationCardProps {
  item: FeedItem
  isSelected: boolean
}

// Colores por capa — consistentes con LayerToggles y FilterPanel
const LAYER_COLORS = {
  clima: '#3b82f6',
  nidos: '#22c55e',
}

export function LocationCard({ item, isSelected }: LocationCardProps) {
  const { activeLayers } = useStore()

  return (
    <div style={{
      padding: '10px 12px',
      borderBottom: '1px solid var(--color-border)',
      cursor: 'pointer',
      background: isSelected ? 'rgba(79,124,255,0.08)' : 'transparent',
      borderLeft: isSelected ? '2px solid var(--accent)' : '2px solid transparent',
    }}>
      <div style={{ fontSize: '13px', fontWeight: 500, marginBottom: '2px' }}>
        {item.name}
      </div>
      <div style={{ fontSize: '11px', color: 'var(--color-text-tertiary)', marginBottom: '6px' }}>
        {item.location}
      </div>

      <div style={{ display: 'flex', gap: '4px', flexWrap: 'wrap' }}>
        {activeLayers.clima && item.climaData && (
          <Tag color={LAYER_COLORS.clima}>
            {item.climaData.weatherIcon} {item.climaData.weather}
          </Tag>
        )}
        {activeLayers.nidos && item.nidoData && item.nidoData.pokemon.map(p => (
          <Tag key={p.id} color={LAYER_COLORS.nidos}>
            {p.icon} {p.name} <span style={{ opacity: 0.6 }}>{p.spawnRate}%</span>
          </Tag>
        ))}
      </div>
    </div>
  )
}

// Componente Tag inline
function Tag({ color, children }: { color: string; children: React.ReactNode }) {
  return (
    <span style={{
      display: 'inline-flex', alignItems: 'center', gap: '3px',
      padding: '2px 6px', borderRadius: '10px',
      fontSize: '10px', fontWeight: 500,
      background: color + '20',
      color: color,
    }}>
      {children}
    </span>
  )
}
```

## Validacion

- [ ] Con solo Clima activo: feed muestra ciudades con tag de weather
- [ ] Con solo Nidos activo: feed muestra parques con NestCard (sprite + nombre + confirmacion)
- [ ] Con ambos activos: lugares con ambos muestran todos los tags; con solo uno muestran ese
- [ ] Badge "Confirmado" visible cuando `confirmed: true` AND `now < nextMigration`
- [ ] Badge "Confirmado" oculto cuando `now >= nextMigration` (aunque JSON diga `confirmed: true`)
- [ ] Countdown muestra "Migra en Xd Yh" cuando falta tiempo
- [ ] Countdown muestra "Migro hace Xh · Sin confirmar" cuando ya paso
- [ ] Countdown se actualiza sin reload (via `store.now`)
- [ ] SD visible solo cuando `stardust` esta definido
- [ ] Stops visibles solo cuando `stops` esta definido
- [ ] Clic en card → pin del mapa se selecciona y mapa vuela a esa ubicacion
- [ ] Clic en pin del mapa → card correspondiente se selecciona, sidebar hace scroll hasta ella
- [ ] Empty state correcto cuando no hay capas activas
- [ ] No hay regresion en la capa de clima (favoritos, filtros existentes)

## Notas

- Los nombres de propiedades exactos en `cities` y `nests` (del store) pueden diferir — verificar con el store real antes de implementar.
- Si `nests` no tiene `placeId` para asociar con ciudades, la deduplicación no aplica — cada nido aparece como ítem independiente. Eso está bien para esta US.
- La sincronización mapa→sidebar (clic en pin → scroll en sidebar) requiere que `selectedCityId` y `selectedNest` en el store se actualicen cuando se hace clic en un pin. Verificar que `MapPin` y `NestPin` ya hacen eso — si no, es parte del scope de esta US.
- Prioridad de sort cuando ambas capas están activas: por defecto mostrar primero los lugares que tienen datos en ambas capas (más información = más útil para decidir).

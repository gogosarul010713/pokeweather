## Historia de Usuario

> Como usuario, quiero buscar ciudades y nidos directamente desde el mapa,
> y tener botones rapidos para cambiar el nivel de zoom sin perderme en el mapa.

---

## Criterios de Aceptacion

### Implementado (sesion 31)
- [x] Campo de busqueda flotante centrado en la parte superior del mapa
- [x] Busca primero en dataset local (ciudades + nidos) con autocomplete
- [x] Sin coincidencia local: opcion de buscar en OpenStreetMap (Nominatim)
- [x] Al seleccionar un resultado dispara FlyToCity / FlyToNest existente
- [x] Shortcut `/` o `Ctrl+K` para abrir el campo de busqueda
- [x] Boton Mundo: zoom 2 con spinner 1200ms antes del zoom out
- [x] Boton Casa: spinner real (espera GPS) → flyTo z13
- [x] Todos los botones agrupados en esquina superior derecha
- [x] Tooltips en todos los botones

### Rediseno aprobado sesion 32 (pendiente de implementar)
- [ ] **Boton Pin eliminado** — coordenadas absorbidas por el campo de busqueda (acepta `lat,lon` directamente)
- [ ] **Boton Lupa+ eliminado** — reemplazado por estructura de 5 botones con 2 separadores
- [ ] Estructura final MapZoomControls (ver DEC-916):
  ```
  Mundo     — vista z2, spinner 1200ms
  Casa      — GPS z13, spinner real
  ─────────
  Mejores   — rota aleatoria entre mejores lugares/nidos del dataset
  Favoritos — rota aleatoria entre favoritos del usuario
  ─────────
  Lupa      — abre search overlay (nombre o lat,lon)
  ```
- [ ] Boton Mejores: al pulsar vuela al siguiente "mejor lugar" en orden aleatorio (segun flag `isBest` del dataset)
- [ ] Boton Favoritos: idem con favoritos personales del usuario (`favorites[]` del store)
- [ ] Ambos botones de rotacion tienen contador visual (ej: "2/5") opcional

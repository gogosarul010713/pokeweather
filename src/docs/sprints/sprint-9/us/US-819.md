---

## Criterios de Aceptación

- [ ] Archivo de datos estáticos en `src/data/nests.json`
- [ ] Los datos de nidos son **independientes** de los datos de clima
- [ ] Estructura de dato de cada nido:
```json
{
  "id": "string (único)",
  "name": "string (nombre del lugar/parque)",
  "city": "string",
  "country": "string",
  "lat": "number",
  "lng": "number",
  "pokemon": "string (nombre del Pokémon nidificado)",
  "pokemonType": ["string"] (array de 1-2 tipos),
  "spawnRate": "number (opcional, porcentaje)",
  "lastReported": "string (opcional, ISO date)"
}
```
- [ ] Mínimo **5 nidos** de diferentes tipos (Water, Fire, Grass, Electric, Dragon, etc.)
- [ ] Distribuidos en diferentes continentes/regiones
- [ ] Coordenadas realistas (lat/lng válidas)
- [ ] Sin typos en nombres de Pokémon ni tipos
- [ ] Tipos válidos según Pokédex oficial (17 tipos base, NO custom types)

## Validación

### Checklist de Validación de Datos

- [ ] Todos los campos obligatorios están presentes
- [ ] Coordenadas son realistas (lat entre -90..90, lng entre -180..180)
- [ ] Nombres de Pokémon son válidos (verificar contra Pokédex)
- [ ] Tipos son válidos (Normal, Fire, Water, Grass, Electric, Ice, Fighting, Poison, Ground, Flying, Psychic, Bug, Rock, Ghost, Dragon, Dark, Steel, Fairy)
- [ ] No hay espacios en blanco inválidos
- [ ] IDs son únicos
- [ ] Fechas en ISO format válido
- [ ] JSON válido (sin trailing commas, etc.)
- [ ] Array tiene mínimo 5 nidos

### Prueba de Carga

```typescript
// En archivo test o console
import nestsData from '@/data/nests.json'

console.log(nestsData.nests.length) // debería ser >= 5
console.log(nestsData.nests[0]) // verificar estructura
```

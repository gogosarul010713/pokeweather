# US-823 — Layer toggles en Header

**Sprint:** 9 — Sesión 3  
**Story Points:** 2  
**Prioridad:** Alta  
**Status:** Pendiente

## Historia de Usuario

> Como jugador, quiero ver botones independientes para cada capa de datos en el header, para poder activar o desactivar Clima, Nidos y capas futuras sin que se excluyan entre sí.

---

## Criterios de Aceptación

- [ ] Componente `LayerToggles.tsx` creado en `src/components/Header/`
- [ ] Un botón por capa: Clima, Nidos, Gimnasios, PokéParadas, Rutas
- [ ] Cada botón refleja visualmente si la capa está activa (color de acento por capa)
- [ ] Al hacer clic llama a `toggleLayer(key)` del store
- [ ] Capas futuras (gyms, stops, rutas) se muestran visualmente deshabilitadas con tooltip "Próximamente"
- [ ] `LayerToggles` integrado en `Header.tsx` en el lugar donde estaba el tab selector
- [ ] El selector anterior de Clima/Nidos (si existía) eliminado de Header
- [ ] Estilos con CSS inline / style prop (no CSS Modules)
- [ ] Funciona correctamente en desktop y tablet (768px+)

## Código de Ejemplo

### `src/components/Header/LayerToggles.tsx`

```tsx
import { useStore } from '../../store/useStore'
import type { LayerKey } from '../../store/useStore'

interface LayerConfig {
  key: LayerKey
  label: string
  icon: string
  color: string
  available: boolean
}

const LAYERS: LayerConfig[] = [
  { key: 'clima',  label: 'Clima',       icon: '🌤',  color: '#3b82f6', available: true },
  { key: 'nidos',  label: 'Nidos',       icon: '🪺',  color: '#22c55e', available: true },
  { key: 'gyms',   label: 'Gimnasios',   icon: '🏟',  color: '#f97316', available: false },
  { key: 'stops',  label: 'PokéParadas', icon: '🔵',  color: '#a78bfa', available: false },
  { key: 'rutas',  label: 'Rutas',       icon: '🗺',  color: '#f59e0b', available: false },
]

export function LayerToggles() {
  const { activeLayers, toggleLayer } = useStore()

  return (
    <div style={{ display: 'flex', gap: '6px', alignItems: 'center' }}>
      {LAYERS.map(({ key, label, icon, color, available }) => {
        const isActive = activeLayers[key]

        const baseStyle: React.CSSProperties = {
          display: 'flex',
          alignItems: 'center',
          gap: '5px',
          padding: '5px 11px',
          borderRadius: '20px',
          border: '1px solid',
          fontSize: '12px',
          cursor: available ? 'pointer' : 'default',
          transition: 'all 0.15s',
          whiteSpace: 'nowrap',
          opacity: available ? 1 : 0.45,
        }

        const activeStyle: React.CSSProperties = isActive && available ? {
          borderColor: color + '60',
          background: color + '20',
          color: color,
        } : {
          borderColor: 'var(--color-border)',
          background: 'var(--color-surface)',
          color: 'var(--color-text-secondary)',
        }

        return (
          <button
            key={key}
            style={{ ...baseStyle, ...activeStyle }}
            onClick={() => available && toggleLayer(key)}
            title={available ? undefined : 'Próximamente'}
            aria-pressed={isActive}
          >
            <span
              style={{
                width: '7px',
                height: '7px',
                borderRadius: '50%',
                background: isActive && available ? color : 'currentColor',
                opacity: isActive && available ? 1 : 0.4,
                flexShrink: 0,
              }}
            />
            {label}
          </button>
        )
      })}
    </div>
  )
}
```

## Validación

- [ ] Los 5 botones se muestran en el header
- [ ] Clima activo por default al cargar (viene del store)
- [ ] Clic en "Nidos" activa la capa sin desactivar Clima
- [ ] Clic en "Clima" (activo) lo desactiva, Nidos permanece sin cambio
- [ ] Gimnasios, PokéParadas y Rutas muestran tooltip "Próximamente" y no responden al clic
- [ ] Estado persiste al recargar (viene de localStorage via store)

- [ ] No hay regresión en el comportamiento del mapa al cambiar capas

## Notas

- No usar CSS Modules — el proyecto usa estilos inline por componente.
- El nombre interno del store es `activeLayers` (objeto), no `activeLayer` (string) — diferente al nombre sugerido en la versión anterior de esta US.
- Los colores por capa son: clima `#3b82f6`, nidos `#22c55e`, gyms `#f97316`, stops `#a78bfa`, rutas `#f59e0b`. Usarlos consistentemente en toda la app (leyenda, pins, tags del sidebar).
- Si el header se ve saturado en mobile (<768px), los toggles pueden colapsar en un menú — evaluar en US de mobile si aplica.

# US-821 — Filtros adaptativos en sidebar por capa activa

**Sprint:** 9 — Sesión 3  
**Story Points:** 3  
**Prioridad:** Alta  
**Status:** Pendiente  
**Dependencias:** US-826 (activeLayers en store), US-823 (LayerToggles)

---

## Historia de Usuario

> Como jugador, quiero que los filtros del sidebar muestren solo las opciones relevantes a las capas que tengo activas, para no ver controles que no aplican a lo que estoy viendo en el mapa.

---

## Criterios de Aceptación

- [ ] `FilterPanel` movido del Header al Sidebar (encima del feed de resultados)
- [ ] Si solo Clima está activo: solo se muestran filtros de clima (weather, tipo, sort)
- [ ] Si solo Nidos está activo: solo se muestran filtros de nidos (tipo Pokémon, sort)
- [ ] Si ambos están activos: ambas secciones de filtros visibles, separadas por divider
- [ ] Si ninguna capa está activa: panel de filtros muestra mensaje "Activa una capa para ver filtros"
- [ ] Cada sección de filtros tiene un label con el color de su capa (igual que los layer toggles)
- [ ] `FilterPanelClima` y `FilterPanelNests` no cambian internamente — solo su visibilidad es controlada por el wrapper
- [ ] El estado de los filtros de cada capa se preserva al desactivar y reactivar la capa

## Código de Ejemplo

### `src/components/Sidebar/FilterPanel.tsx`

```tsx
import { useStore } from '../../store/useStore'
import { FilterPanelClima } from '../Header/FilterPanelClima'   // ajustar path si se mueven
import { FilterPanelNests } from '../Header/FilterPanelNests'

const sectionLabelStyle = (color: string): React.CSSProperties => ({
  display: 'flex',
  alignItems: 'center',
  gap: '6px',
  fontSize: '10px',
  fontWeight: 600,
  textTransform: 'uppercase',
  letterSpacing: '0.5px',
  color,
  marginBottom: '6px',
})

const dotStyle = (color: string): React.CSSProperties => ({
  width: '7px',
  height: '7px',
  borderRadius: '50%',
  background: color,
  flexShrink: 0,
})

export function FilterPanel() {
  const { activeLayers } = useStore()
  const hasAny = activeLayers.clima || activeLayers.nidos

  if (!hasAny) {
    return (
      <div style={{
        padding: '12px',
        fontSize: '12px',
        color: 'var(--color-text-tertiary)',
        textAlign: 'center',
        borderBottom: '1px solid var(--color-border)',
      }}>
        Activa una capa para ver filtros
      </div>
    )
  }

  return (
    <div style={{
      borderBottom: '1px solid var(--color-border)',
      display: 'flex',
      flexDirection: 'column',
      gap: '0',
    }}>
      {activeLayers.clima && (
        <div style={{ padding: '10px 12px', borderBottom: activeLayers.nidos ? '1px solid var(--color-border)' : 'none' }}>
          <div style={sectionLabelStyle('#3b82f6')}>
            <span style={dotStyle('#3b82f6')} />
            Clima
          </div>
          <FilterPanelClima />
        </div>
      )}

      {activeLayers.nidos && (
        <div style={{ padding: '10px 12px' }}>
          <div style={sectionLabelStyle('#22c55e')}>
            <span style={dotStyle('#22c55e')} />
            Nidos
          </div>
          <FilterPanelNests />
        </div>
      )}
    </div>
  )
}
```

## Validación

- [ ] Con solo Clima activo: solo aparecen los filtros de clima en el sidebar
- [ ] Con solo Nidos activo: solo aparecen los filtros de nidos
- [ ] Con ambos activos: ambas secciones con su label de color correspondiente
- [ ] Con ninguno activo: mensaje "Activa una capa para ver filtros"
- [ ] Filtrar por clima "Soleado" reduce los resultados del feed
- [ ] Cambiar de capa no resetea los filtros de la otra capa
- [ ] El panel no ocupa espacio excesivo cuando hay una sola sección
- [ ] No hay regresión en los filtros existentes de FilterPanelClima y FilterPanelNests

---

## Notas

- El estado interno de `FilterPanelClima` (weather seleccionado, tipo seleccionado) no cambia — solo su visibilidad.
- Si los filtros de clima ya están en el store (Zustand), la persistencia entre capas es automática. Si están en estado local del componente, se perderán al desmontar — en ese caso evaluar moverlos al store.
- Los dividers y el label de color son el único elemento visual nuevo. Los filtros en sí son los mismos componentes existentes.
- Prioridad de espacio: el sidebar tiene altura limitada. Si ambas secciones de filtros son largas, agregar `overflow-y: auto` con `max-height` definido en el wrapper del FilterPanel.

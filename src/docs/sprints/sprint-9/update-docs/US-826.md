# US-826 — Migración de `activeTab` a `activeLayers` en Zustand

**Sprint:** 9 — Sesión 3  
**Story Points:** 3  
**Prioridad:** Crítica  
**Status:** Pendiente  
**Dependencias:** Ninguna (es la base de US-821, US-823, US-824, US-818)

---

## Historia de Usuario

> Como desarrollador, quiero reemplazar el string `activeTab` por un objeto de booleanos `activeLayers` en el store global, para que cada capa de datos pueda activarse y desactivarse de forma independiente sin valores especiales.

---

## Criterios de Aceptación

- [ ] `activeTab` y `setActiveTab` eliminados del store completamente
- [ ] `activeLayers: ActiveLayers` presente en el store con default `{ clima: true, nidos: false, gyms: false, stops: false, rutas: false }`
- [ ] `toggleLayer(key)` alterna el booleano de una capa y persiste en localStorage
- [ ] `setLayer(key, value)` permite forzar un valor específico
- [ ] localStorage usa key `pwe-activeLayers` (JSON) en lugar de `pwe-activeTab` (string)
- [ ] `MapView.tsx` actualizado para usar `activeLayers.clima` y `activeLayers.nidos` en lugar de comparaciones con string
- [ ] Build sin errores TypeScript en todos los archivos que consumían `activeTab`
- [ ] El tipo `LayerKey` y la interfaz `ActiveLayers` exportados desde el store

## Código de Ejemplo

### `src/store/useStore.ts` — tipos y estado

```ts
// Agregar antes del store o en src/types/layers.ts
export type LayerKey = 'clima' | 'nidos' | 'gyms' | 'stops' | 'rutas'

export interface ActiveLayers {
  clima: boolean
  nidos: boolean
  gyms: boolean
  stops: boolean
  rutas: boolean
}

const DEFAULT_LAYERS: ActiveLayers = {
  clima: true,
  nidos: false,
  gyms: false,
  stops: false,
  rutas: false,
}

// Dentro del store, reemplazar activeTab por:
activeLayers: ((): ActiveLayers => {
  try {
    const stored = localStorage.getItem('pwe-activeLayers')
    if (!stored) return DEFAULT_LAYERS
    const parsed = JSON.parse(stored)
    // Merge con defaults para tolerar keys nuevas en el futuro
    return { ...DEFAULT_LAYERS, ...parsed }
  } catch {
    return DEFAULT_LAYERS
  }
})(),

toggleLayer: (layer: LayerKey) =>
  set((state) => {
    const next = { ...state.activeLayers, [layer]: !state.activeLayers[layer] }
    localStorage.setItem('pwe-activeLayers', JSON.stringify(next))
    return { activeLayers: next }
  }),

setLayer: (layer: LayerKey, value: boolean) =>
  set((state) => {
    const next = { ...state.activeLayers, [layer]: value }
    localStorage.setItem('pwe-activeLayers', JSON.stringify(next))
    return { activeLayers: next }
  }),
```

# US-824 — Layout general: mapa como protagonista

**Sprint:** 9 — Sesión 3  
**Story Points:** 2  
**Prioridad:** Alta  
**Status:** Pendiente  
**Dependencias:** US-826 (activeLayers en store)

---

## Historia de Usuario

> Como jugador, quiero que el mapa ocupe el espacio central de la pantalla con el sidebar fijo a la izquierda, para tener una experiencia de exploración donde el mapa siempre es visible.

---

## Criterios de Aceptación

- [ ] Layout principal: `display: flex`, sidebar fijo a la izquierda, `MapView` con `flex: 1`
- [ ] Sidebar tiene ancho fijo (300px desktop, 280px tablet)
- [ ] El mapa ocupa todo el espacio restante y no hace scroll — la página entera tiene `height: 100vh`, `overflow: hidden`
- [ ] Sidebar puede colapsarse (toggle existente en Header), el mapa expande al colapsar
- [ ] Transiciones de 300ms en el sidebar al colapsar/expandir
- [ ] Z-index scale documentado: mapa base (0), pins (10), sidebar (20), header (30), modales (100)
- [ ] `MapView.tsx` permanece como archivo único — sin separación en subcarpetas en esta US

## Código de Ejemplo

### `src/App.tsx` — layout raíz

```tsx
// Estructura base
<div style={{
  display: 'flex',
  flexDirection: 'column',
  height: '100vh',
  overflow: 'hidden',
}}>
  <Header />   {/* height fija, ~52px */}

  <div style={{
    display: 'flex',
    flex: 1,
    overflow: 'hidden',
  }}>
    <Sidebar />       {/* ancho fijo, colapsable */}
    <MapView />       {/* flex: 1, ocupa el resto */}
  </div>
</div>
```

### `src/components/Sidebar/Sidebar.tsx` — colapso con transición

```tsx
const { sidebarOpen } = useStore()   // o el nombre real del flag en el store

<div style={{
  width: sidebarOpen ? '300px' : '0px',
  minWidth: sidebarOpen ? '300px' : '0px',
  overflow: 'hidden',
  transition: 'width 300ms ease, min-width 300ms ease',
  borderRight: '1px solid var(--color-border)',
  display: 'flex',
  flexDirection: 'column',
  zIndex: 20,
  position: 'relative',
}}>
  {/* contenido del sidebar */}
</div>
```

### `src/components/Map/MapView.tsx` — contenedor

```tsx
// El componente MapView ocupa el espacio restante
<div style={{
  flex: 1,
  position: 'relative',
  zIndex: 0,
  overflow: 'hidden',
}}>
  {/* MapContainer de react-leaflet aquí */}
  {/* Leyenda, detail panel, time chip — position: absolute dentro */}

```

### Z-index scale

## Validación

- [ ] El mapa ocupa todo el viewport menos el header y el sidebar
- [ ] Colapsar sidebar expande el mapa suavemente en 300ms
- [ ] No hay scroll vertical en la página principal
- [ ] Los pins del mapa son visibles sobre el fondo del mapa (z-index correcto)
- [ ] El header está siempre encima del sidebar y del mapa
- [ ] Modales (ClassificationReportModal, etc.) aparecen sobre todo el contenido
- [ ] Layout correcto en desktop (1280px+) y tablet (768–1023px)

---

## Notas

- **Importante:** el código de ejemplo de la versión anterior de esta US sugería separar `MapView` en `ClimateMapView` y `NestMapView`. Ese refactor **no es parte de esta US**. `MapView.tsx` permanece como archivo único. Ver DEC-903 en decisions.md.
- El flag de colapso del sidebar puede ser `sidebarOpen`, `isSidebarVisible`, o el nombre que ya exista en el store — verificar antes de implementar.
- Si el sidebar ya tiene estilos de ancho, reemplazarlos por el patrón `width` + `transition` del ejemplo para que la animación funcione correctamente. `display: none` no anima.

# US-801 — Persistir Pronóstico por Ciudad

**Sprint:** 8  
**Priority:** P1  
**Story Points:** 3  
**Status:** ✅ COMPLETADO  
**Commit:** `61ece21` (fix duplicados), `bddadcc` (catalog)

---

## Problema

Pronósticos climáticos se pierden, sin histórico para auditar clasificación.

---

## Solución

Guardar pronóstico horario (12h snapshots) en Firestore cada ciclo de actualización.

---

## Schema Firestore

```
/city_weather/{city_id}/forecasts/{YYYY-MM-DD-HH}
  ├── snapshots: ForecastSnapshot[]  (12 elementos)
  ├── created_at: Timestamp
  └── ttl: Timestamp (now + 7 días)
```

---

## Criterios de Aceptación

- [x] Pronóstico guardado en Firestore (async/background)
- [x] Falla silenciosa si offline
- [x] 12 horas por ciclo guardadas
- [x] TTL field presente (para US-806)
- [x] Optimizado: sin escrituras duplicadas

---

## Optimizaciones

- **Async:** No bloquea UI
- **Fallback:** Continúa si Firestore offline
- **Dedup:** -50% escrituras (removido guardado duplicado)

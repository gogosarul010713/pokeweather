## Problema

Bottom Sheet (LocationDetail panel) no era visible en mobile porque:
1. `#root { overflow: hidden }` bloqueaba elementos `position: fixed`
2. Leaflet controles (z-index: 1000) tapaban el panel (z-index: 50)

---

## Solución

### Fix 1: Portal Escape
- Crear `#bottom-sheet-root` fuera de `#root`
- Usar `createPortal()` para renderizar BottomSheet
- Resultado: escape de overflow: hidden

### Fix 2: Z-Index Hierarchy
- BottomSheet: z-index 1000 → 1001
- Todos los overlays sobre mapa: ≥ 1001

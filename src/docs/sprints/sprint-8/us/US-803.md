**Status:** ✅ COMPLETADO

---

## Problema

Dashboard (TestingTools) solo muestra métricas en-memoria.

---

## Solución

Leer métricas desde Firestore con fallback automático:
1. Try: Firestore queries
2. Catch: En-memoria (IndexedDB fallback)

---

## Arquitectura

```
PrecisionMetrics.tsx
  ├─ Try: getRecentForecasts() [Firestore]
  │  └─ Firestore collectionGroup query
  ├─ Catch: Fallback [IndexedDB]
  │  └─ Process timestamps en-memoria
  └─ Display: Métricas de precisión
```

---

## Criterios de Aceptación

- [x] Dashboard lee desde Firestore
- [x] Fallback automático si offline
- [x] Métricas actualizadas correctamente
- [x] Selectores Firestore/IndexedDB visible
- [x] Zero functional regression

---

## Nota Técnica

Firestore collectionGroup queries sin índice:
- **Limitación:** No acepta orderBy sin índice
- **Workaround:** Fetch todo, procesar timestamps en JS
